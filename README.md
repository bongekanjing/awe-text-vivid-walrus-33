# A hole in a hill, keeping count

`main.py` writes one short text to `entry.txt` — in `/output`, or in
`$MAKEFUN_OUTPUT_DIR` when that is set. Nothing else: no network, no
dependencies beyond the Python 3.13 standard library. It prints the
code-point count on the way out.

```
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

The text:

```
They took the hill apart
and left a hole for the rain.

The rain has filled it an inch a year
and the far wall keeps count:
one pale line for every summer,
more lines than the town below has people.

The bottom stone is shells.
The sea was here first
and is not finished.
```
